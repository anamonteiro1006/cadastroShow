Este é um sistema de gerenciamento de lista de convidados desenvolvido para fins de estudo. O objetivo principal foi praticar a integração entre o \*\*PHP\*\* e o banco de dados \*\*MySQL\*\*, permitindo o cadastro de pessoas interessadas em participar de um evento (Show do Luan Santana).

## 🛠️ Funcionalidades

* **Cadastro de Usuários:** Formulário para inserção de dados no banco.
* **Listagem:** Visualização dos usuários já cadastrados.
* **Integração com Banco de Dados:** Persistência de dados utilizando o driver PDO ou MySQLi.


## 💻 Tecnologias Utilizadas

- PHP: Lógica de back-end.
- MySQL: Armazenamento de dados.
- CSS: Estilização da interface.
- XAMPP: Ambiente de desenvolvimento local.

## 🔰Como inicializar o projeto
- Faça download do XAMPP no seu computador: https://www.apachefriends.org/pt_br/index.html
- Faça o download do arquivo pelo github e coloque na pasta htdocs no XAMPP.
- Abra o XAMPP e habilite o APACHE
- Coloque a seguinte url no navegador: localhost/cadastroShow-main/
